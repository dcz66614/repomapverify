## Notes on planted-class mapping

- The 8 menu classes from the task card are covered exactly for
  TypeScript (one fixture per class).
- Go has no dynamic import and no re-export, so two classes use
  documented Go analogues: dynamic-import-misread → build-tag-misread
  (an edge existing only in a file excluded from the frozen build,
  go-plant-08); re-export-misread → transitive-closure misread
  (go-plant-07). Alias-misparse for Go is the replace-directive
  analogue (go-plant-06).
- Generated-file handling is proven by go-ctrl-03 (control): a claimed
  map that counted generated edges as core would fail parity/audit.
- Cascades are expected findings, not extra defects: omitting a
  reachable module necessarily also omits its incoming edge
  (MISSING_EDGE), and a name-collision plant necessarily leaves the
  shadowed module unclaimed (UNCLAIMED_REACHABLE_MODULE). Both are
  recorded in the golden expectedFindings.
- One golden correction during the PoC run: go-ctrl-07
  externalImportCount 2 → 3 (re-reasoned: `fmt` is imported by
  cmd/main.go, internal/app/app.go AND vendor/.../bar.go = 3
  occurrences; the extractor was right, the hand-written golden was
  wrong). Recorded here, not silently copied from extractor output.
